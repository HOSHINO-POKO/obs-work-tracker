# 本日のチャレンジ

配信画面に出せる、やることリスト付きの作業トラッカーです。  
OBS のブラウザソースに読み込んで使います。

このツールは **HOSHINO-POKO の自作** です。  
公式ツールではありません。

## 禁止事項

- 再配布（転載、アップロードし直し、二次配布、ミラー）
- 自作と偽ること
- 有料販売、バンドル販売
- 公式・公認であるかのような表記

個人で使う分、自分の配信で映す分は問題ありません。  
改変して自分の配信で使うのもかまいません。ただし改変版の再配布も禁止です。

## OBSへの入れ方

1. 使いたい `.html` を保存する
2. OBS → ソース → **ブラウザ**
3. 「ローカルファイル」でその HTML を指定する
4. 幅 `720` / 高さ `900` くらい
5. プレビュー上でソースを選び、**Alt を押しながら右端をドラッグ**して、右の操作欄を切る
6. 操作するときはソースを右クリック → **対話**
7. 対話ウィンドウを横に広げると、右に ＋ と一括追加欄が出る

シーンを切り替えるたびに時間が戻る場合は、ブラウザソース設定の  
「シーンがアクティブになったときにブラウザを更新」をオフにしてください。

## 使い方

- **開始 / 一時停止** … 経過時間の計測
- **時間リセット** … 経過時間だけゼロに戻す（タスクは残る）
- **＋** … 行を1つ追加する
- **チェック** … 完了。そのときの経過時間が右に出る
- **タスク名** … 対話で直接書き換え（日本語変換が弱いことがあります）
- **×** … その行を削除

### 日本語でまとめて追加

OBSの対話は日本語入力が不安定です。次の方法が確実です。

1. メモ帳でタスクを書く（1行が1件）
2. 対話の「まとめて追加」欄に貼る
3. **貼り付けて追加** を押す

例:
ショート動画作成
ご飯食べる
お風呂入る


## 色・見た目について

色違いは配色を変えただけで、操作は同じです。  
クエスト画面風は雰囲気を参考にした非公式デザインです。特定のゲームの公式素材・ロゴは使っていません。公式・公認ではありません。
